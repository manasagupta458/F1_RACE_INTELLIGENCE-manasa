# F1_RACE_INTELLIGENCE-manasa

📌 Project Overview

The Formula 1 Race Intelligence Dashboard is a data visualization project developed using Tableau. It provides insights into race performance, driver performance, team performance, pit stop comparisons, and circuit analysis.

🎯 Project Objectives

* Analyze Formula 1 race performance.
* Compare driver performance.
* Evaluate team performance.
* Analyze pit stop data.

🛠️ Tools Used

* Tableau Public
* Microsoft Excel
* GitHub

📊 Live Dashboard

View the interactive Tableau Public dashboard and story here:

📁 Project Files

🚀 How to View the Project

1. Open the Tableau Public dashboard link above to explore the interactive visualizations.
2. Download the .twbx file from this repository to open the workbook in Tableau Desktop or Tableau Public.
