Phase 1: Project Overview

Project Title

Formula 1 Race Intelligence Dashboard

Project Description

The Formula 1 Race Intelligence Dashboard is a data visualization project developed using Tableau. It presents Formula 1 racing information through interactive visualizations to help users explore race performance and understand patterns in the available data.

Project Objectives

* Analyze Formula 1 racing information.
* Present insights using charts and graphs.
* Build an interactive Tableau dashboard.
* Create a Tableau Story for presenting visual insights.
* Publish the dashboard and story on Tableau Public.

Tools and Technologies

* Tableau Public
* Microsoft Excel
* GitHub

Expected Outcome

A Tableau-based dashboard and story that present Formula 1 data in a clear and format.
