Phase 2: Data Preparation

Objective

To prepare the Formula 1 dataset for visualization and analysis in Tableau.

Data Preparation Process

The data preparation stage focuses on organizing the available Formula 1 data so it can be used effectively in the dashboard.

The main activities include:

* Reviewing the available data fields.
* Checking data types and field formats.
* Identifying missing or inconsistent values.
* Ensuring that relevant fields are suitable for visualization.
* Preparing the data for use in Tableau charts and dashboard views.

Tableau Integration

The prepared data is used in Tableau to create visualizations and support interactive analysis.

Expected Outcome

A dataset structured appropriately for creating meaningful Formula 1 visualizations.
